# RKF-AK3-REPO
为ReKernelFlasher软件提供云上AK3
## 介绍
1.本仓库主要为RKF软件云GKI功能提供资源支持
2.本仓库主要使用(cctv18)[https://github.com/cctv18]作者的Github Action流进行编译
## 注意
1.刷入Anykernel3时请注意备份boot.img，方便不开机时进行救砖操作
2.请根据机型选择适合的包进行刷入，如果因为您的选错了包的原因导致设备出现问题，本仓库概不负责
### 备注
1.如果您也想将自己有效的Anykernel3包上传至此仓库供其它人使用，可以联系我
2.欢迎积极反馈issues
