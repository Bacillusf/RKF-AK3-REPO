# RKF-AK3-REPO

为 ReKernelFlasher 软件提供云端 AnyKernel3 资源。

## 介绍

1. 本仓库主要为 RKF 软件的云 GKI 功能提供资源支持。
2. 本仓库使用 [cctv18](https://github.com/cctv18) 作者的 GitHub Actions 工作流进行编译。

## 注意

1. 刷入 AnyKernel3 前，请务必备份 `boot.img`，以便在无法开机时进行救砖操作。
2. 请根据您的机型选择适合的刷机包。若因选错包导致设备出现问题，本仓库概不负责。

### 备注

1. 如果您也希望将自己有效的 AnyKernel3 包上传至本仓库供他人使用，欢迎联系我。
2. 欢迎积极提交 issues 或反馈建议。
